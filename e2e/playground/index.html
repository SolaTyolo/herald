Herald Playground

In-app

写入订阅者并触发 playground-inapp。asynq 模式需要 worker 在跑。


  


  

    
SMTP

    
凭据来自 API/Worker 环境变量 SMTP_HOST / SMTP_PORT / SMTP_FROM / SMTP_USERNAME / SMTP_PASSWORD。此处只触发 playground-email。

    
    
    
    
    

    

  


  

    
Template

    
动态模板：创建并激活一个 version，可预览，也可填到 In-app、SMTP 或 Workflow 再发送。

    
    
    
    
    
    

      
      
      
      
      
    

    

    
    

  


  

    
Workflow

    
创建或更新工作流，再按一个订阅者或一个 Topic 触发。triggerId 就是 POST /v1/events/trigger 的 name。步骤里有 templateId 时不用内联 template。
